How this demo works

Works in your browser

Navigation, likes, follows, comments, saves, profile edits, uploaded local previews, chat messages, preferences, and offline creative prompts work directly in this demo.

Production needs secure infrastructure

Real authentication, database sync, real-time chat, permanent video storage/CDN delivery, push notifications, production AI, HTTPS, reporting, and moderation require a secure backend and appropriate privacy controls.

Do not use this demo for real credentials or private information. Future integrations should use secure authentication, server-side validation, an AI proxy, object storage, moderation tooling, and HTTPS.
